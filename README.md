## FAQ

### What is XCutors?

XCutors is a curated collection of popular Roblox script executor tools bundled with a universal loader called xcutorsLoader. It provides a single download and management interface for multiple executors including Volt, Synapse Z, Potassium, and Wave.

### Is XCutors free to use?

Yes, the xcutorsLoader and this repository are completely free. However, some individual executors included in the collection may have their own licensing or access requirements set by their original developers.

### Which Windows versions are supported?

XCutors supports Windows 10 (version 1903 and later) and Windows 11. Both 64-bit and 32-bit architectures are supported, though 64-bit is recommended for optimal performance.

### Why does my anticomponent flag the loader or executors?

Script executors work by interacting with external processes, which can trigger heuristic-based anticomponent detections. You may need to add an exclusion for the XCutors folder in your anticomponent software. Always download from this official repository to ensure file integrity.

### Can I use XCutors on macOS or Linux?

No, XCutors and all included executors are designed exclusively for Windows desktop. There are no current plans for cross-platform support, as the underlying execution methods rely on Windows-specific APIs.

### How do I update the executors?

The xcutorsLoader includes a built-in auto-update feature. When you launch the loader, it automatically checks for new versions of each executor. You can also manually trigger an update by clicking the 'Check for Updates' button in the settings menu.

### Where can I find scripts to run?

XCutors includes a built-in script hub with categorized community scripts. You can also find scripts on popular Roblox scripting communities and forums. Simply copy the script code and paste it into the executor's editor, or save it as a .lua file and load it via the file browser.

### What should I do if an executor fails to attach?

Ensure Roblox is fully loaded and you are in an active game session before clicking Attach. Run the loader as administrator, temporarily disable your anticomponent, and make sure no other executor instances are running. If the issue persists, try reinstalling the executor through the loader dashboard.

### Is there a risk of getting banned from Roblox?

Using any third-party script executor carries inherent risk, including potential account suspension or permanent ban by Roblox. Use these tools responsibly and at your own discretion. Consider using alternate accounts for testing purposes.

### How do I report bugs or request features?

Please open an issue on this GitHub repository using the appropriate issue template. Provide detailed information including the executor name, steps to reproduce the problem, your Windows version, and any error messages from the console output.
